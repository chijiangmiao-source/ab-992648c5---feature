光阑换位操作可导出性审计

在 Web Worker 中按端口标识排序建立确定性 Schreier–Sims 稳定子链， 由横截代表逐层复算判定目标置换能否由允许的换位操作导出； 可进一步把端口编入允许内部互换的校准组，在既有稳定子链上递归构造 分块传送子与集合稳定子，判定组内重标后能否导出目标接线。

1. 稳定端口（2–12 个，空格/逗号分隔）

2. 具名置换操作（至多 8 个）

支持循环记号 (A B)(C D) 或显式映射 A->B, B->A； 操作允许执行其逆操作。每个操作必须是全部端口上的双射。

3. 目标置换

4. 校准编组（可选）

把允许内部互换的端口编入同一校准组，组间以 ; 或换行分隔，如 A B; C D 或 (A B)(C D)；未列出的端口不与任何端口互换。 留空则不启用编组容差，按原规程做精确可导出性判定。

审计结论

填写规程后点击“发起审计”。

操作因子链逐步回放

成员判定仅使用稳定子链横截剥离复算，不枚举全部操作串、不使用随机搜索、不以有限深度回放代替。
